# 从网盘恢复媒体库

重新部署或重建数据库后，先在设置中重新绑定原网盘，在对应网盘的媒体库顶部点击「同步网盘资源」。同步扫描该盘已绑定的 Movies、TV、Anime 分类目录，并补回缺失的作品、季度、元数据和已入库集号。空媒体库也提供入口。

优先按原项目目录的 `{tmdb-数字}` / `{anilist-数字}` 标识定位作品；旧的 `片名 (年份)` 目录只有在片名、年份及电影/剧集类型唯一匹配时才导入。剧集读取 `Season N` 季度目录及文件名中的集号；AniList 动画条目仍使用条目自身的相对集号，不把播出季度当成作品季数。视频文件实际存在且大小大于零才恢复已入库状态，字幕、预告、样片和 staging 临时文件不计入。

同步只读网盘并写入媒体库数据库，不下载、不转存、不重命名、不移动、不删除文件。仅补回缺失记录，已有记录跳过，不覆盖已有追踪和手动状态；重复点击可安全重试。同一进程中的同盘同步共用正在进行的任务，数据库的原有原子预留也会避让正在获取的作品。部分目录失败不会回滚已经恢复的其他作品。

同步完成后展开「查看未同步内容」核对问题。元数据不可用、片名不唯一、非标准目录、文件集号与季度不一致等情况不会强行认领。扫描限于每个电影/季度目录下四层文件子目录，网盘其他目录不在范围内。同步不会把文件名无法确认的集数猜成已入库。

界面会显示新增作品/季度、恢复集/部、已有跳过和待核对项数。进行中或仍缺集的剧集保持追踪状态，完全播出且文件齐全的季度标为完成；同步本身不排队下载。旧的聊天、获取历史、源链接和用户设置无法仅从网盘文件重建，仍需数据库备份。
